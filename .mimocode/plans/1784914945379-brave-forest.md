# Plan: Botón para Agregar Nuevo Estudiante

## Contexto

El usuario quiere un botón para agregar un nuevo estudiante, similar a la ficha de estudiante, donde pueda ingresar los mismos datos y pegar fotografía, guardando en Supabase.

**Hallazgo:** Esta funcionalidad YA EXISTE en la app:
- Botón "Nuevo" en `StudentsPage.tsx:122` → abre `StudentFormModal`
- `StudentFormModal` tiene todos los campos (nombre, curso, diagnóstico, orientaciones, adecuación)
- Soporta subir foto por archivo Y pegar con Ctrl+V
- Guarda en Supabase via `handleAddStudent` en `App.tsx`

## Problema

El botón "Nuevo" **solo aparece** cuando el usuario está en la vista de estudiantes (`view === 'students'`). No es accesible desde:
- El Dashboard (vista principal)
- El Header principal

## Propuesta

Agregar un botón flotante (FAB) visible en TODAS las vistas que permita crear un nuevo estudiante rápidamente, sin importar en qué vista esté el usuario.

### Cambios

**Archivo: `src/App.tsx`**
- Agregar un botón flotante (Fixed Action Button) en la esquina inferior derecha
- Visible solo para admin (`isAdmin`)
- Al hacer clic, abre el `StudentFormModal` existente
- Estilo:圆形 verde con icono `Plus` de lucide-react

### Código a agregar (después del `</AnimatePresence>`, antes de `</main>`)

```tsx
{isAdmin && (
  <button
    type="button"
    onClick={() => setIsAddingStudent(true)}
    className="fixed bottom-6 right-6 md:bottom-8 md:right-8 z-40 w-14 h-14 bg-brand-accent text-white rounded-full shadow-lg shadow-brand-accent/30 flex items-center justify-center hover:bg-emerald-600 hover:scale-110 transition-all active:scale-95"
    aria-label="Agregar nuevo estudiante"
  >
    <Plus className="w-6 h-6" />
  </button>
)}
```

## Verificación

1. Ejecutar `npm run dev`
2. Verificar que el botón flotante aparece en todas las vistas (Dashboard, Estudiantes, Guía)
3. Verificar que solo aparece para admin
4. Hacer clic → abrir modal de nuevo estudiante
5. Llenar datos + pegar foto → guardar → verificar que aparece en la lista
6. Verificar en Supabase que el registro se creó correctamente
